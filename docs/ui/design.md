# UI 设计说明

状态：待核实；日期：2026-10-28。实现：C:/Users/ldy/Desktop/检测记录查询工具练习/record_query/ui.py。

- UID-01：中文主窗口“检测记录查询工具”，初始约 960×620，可缩放，基础最小 740×460；最小高度随新增筛选行动态增加，至少保留 110 像素表格区域和底部导出按钮。顶部导入按钮和只读路径。初始提示选择文件，导出禁用。
- UID-02：modality/review_status 各一个动态下拉组，初始一个“全部”；“+ 增加条件”添加“请选择”空框，多框不再提供“全部”。同组各框排除其他框已选项，当前框保留自己的值；空框不参与筛选。每行可移除，最多六个模态框/两个状态框，满额禁用增加，移除后恢复。组内 OR、组间 AND，即时更新；重置和重新导入恢复各组一个“全部”。统计以“总数、待复核、已复核”显示。三列 Treeview 只读，允许横纵滚动，不增加业务编辑。
- UID-03：导出按钮使用保存对话框，默认 exports/筛选结果.csv；如果名称已存在，提示换新名字。合法空表/零结果允许导出。取消不改变状态。错误弹窗标明原因；导入失败清空旧结果，导出失败保留当前查询。

触发、订阅和服务双向关系见 UI 总表和 FU-UI-0001；无后台线程或额外窗口。高 DPI/其他机器验收未经执行不标记通过。
