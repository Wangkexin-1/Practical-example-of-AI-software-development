## 数据流、权威源变化与结构适配

外部 UTF-8/UTF-8 BOM 文件 → 严格 CSV 解析及全文件校验 → 不可变 Record 元组和 LoadedData → AV-0001 QuerySession → Result（记录元组与总数/待复核/已复核）→ UI 表格/统计，或新 UTF-8 BOM CSV。

AV-0001 在主窗口创建时初始化：data=None、modality=None、review_status=None。Record 三字段均为 str，无单位/坐标；record_id 不增加唯一性或格式限制。LoadedData 保存源文件 resolve 路径、读取时文件标识（device/inode）、不可变记录元组。筛选结果由 AV 统一派生，不从表格反读。UI 下拉值通过事件 payload 写入 AV，不是业务计算的权威来源。

CSV 必须具有 record_id/modality/review_status，可调换顺序并有额外列；重复表头拒绝。忽略完全空白的 CSV 行，非空行字段数必须与表头相同。枚举精确匹配，不自动 trim、变换大小写或去重。缺文件、缺列、空枚举、非法枚举、错误编码、损坏语法均终止；仅合法表头是正常 0 条。

新结构的读写者全部首次建立，无旧结构迁移。读者：FU-0002/0003、FU-UI-0001；写者：FU-0001/0002。失败导入清空 AV 和筛选，关闭导出；取消对话框不触发导入，保留现状。窗口关闭释放会话，不保存用户会话。

## 条款索引与详细功能元

- UI-01/UID-01/UIW-01：导入区 → FU-0001 → AV-0001 → 统一刷新。
- UI-02/UID-02/UIW-02：两个只读下拉及重置 → FU-0002 → AV-0001 → 表格及统计。
- UI-03/UID-03/UIW-03：导出按钮 → FU-0003；空合法数据允许导出，无有效文件时禁用。

FU-0001：同步执行，仅当整文件成功解析才提交 LoadedData；临时记录在异常时释放；错误含文件和具体原因，数据行错误含物理行号及字段/值。取消不调用处理。

FU-0002：读取不可变原记录，None 表示全部，两个非 None 条件按且；保留原顺序；三项计数由同一结果产生，满足 total=pending+reviewed。重置只清空条件。

FU-0003：从 AV 取得结果；比较规范化路径和已有目标的文件身份，包括导入时标识，拒绝同源及所有已存在目标。采用独占创建（x）防止检查后覆盖竞态；保留三列表头及字段原值，用 csv.writer 转义；成功终点关闭文件。写失败清理本次创建且身份一致的不完整文件；不修改输入；取消不创建文件。

FU-UI-0001：导入区、筛选区、统计区、带双向滚动条的只读表格、导出按钮、状态栏。只负责布局/事件/对话框/显示；所有业务由 QuerySession 服务。控制键快捷键可操作；导入和导出取消均不改变状态。关闭销毁窗口和会话，不运行后台任务。

### 目标、范围与数据契约

modality 与 review_status 各有独立“+ 增加条件”按钮，追加同组下拉框。组内已选值从其他下拉选项中排除，当前框保留自身所选值供更换；一个组的选择不影响另一组的可选枚举。

同组多个值按 OR（属于集合任一值）匹配，两组按 AND；例如 modality=U/V 且 review_status=待复核时，仅保留 U 或 V 的待复核记录。同时选择两个状态不限制状态。没有有效条件时全部显示。表格顺序、三项统计和导出都基于同一 Result，不复制或重复输出记录。

UI 初始仍为一个“全部”。增加框后空白框显示“请选择”，未选择的框不参与筛选，不自动替用户选择枚举；已有“全部”显示改为“请选择”。多框时不显示“全部”，避免“全部 OR U”的歧义。每框提供“移除”；只剩一个框且无选择时恢复“全部”。模态最多六个框，状态最多两个框，到达上限禁用增加按钮；移除后重新可加。重置、重新导入及导入失败均恢复每组一个“全部”；文件对话框取消保持条件和空白框。
