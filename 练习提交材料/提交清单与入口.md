## 直接运行

在本目录双击“运行查询工具.cmd”或“演示主样例.cmd”。入口自动进入“源码”目录，使用其虚拟环境（如有）或系统 Python。

需要 Windows 上的 Python 3.11+，安装包含 Tcl/Tk。提交材料不带 .venv 或 Python 解释器，在当前机器可使用已安装的 Python。新机器可以在“源码”目录运行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe main.py
```

无第三方运行依赖，无需在线下载业务包。详细操作见运行说明.md。演示入口直接打开 18 条主样例；选 U/V 得到 7/4/3，再选待复核得到 4/4/0，可导出 S001、S002、S003、S005。
